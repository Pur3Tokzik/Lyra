# Lyra

Lyra is a local-first open source AI system designed to create personalized AI companions with their own identity, personality and memory.

## Vision

Create a fully local AI framework where users can create and maintain their own AI instance.

The AI model is a capability. The identity belongs to the AI instance itself.

## Current Status

Lyra 0.0.1 is under active development.

## Implemented

### Core Architecture
- AI instance architecture
- Dependency injection based design
- Identity system
- Personality system
- Onboarding architecture

### Memory & History
- Memory subsystem
- Memory repository abstraction
- File-based memory persistence
- Journal system foundation
- Conversation and event history structures

### Model Integration
- Abstract model interface
- Model provider architecture
- Local Ollama integration
- Local LLM communication support

### Persistence
- AI state persistence foundation
- Memory persistence
- Journal persistence foundation

## Current Development Focus

### Brain Coordination System

The next development phase focuses on integrating the existing components through a coordinated orchestration layer.

The Brain will become responsible for coordinating:

- Identity context
- Personality behaviour
- Memory retrieval
- Journal history
- Model communication

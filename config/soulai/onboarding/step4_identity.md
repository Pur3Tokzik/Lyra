# SoulAI 0.0.1 — ONBOARDING

## 5. Identidade do utilizador

A IA faz a primeira pergunta sobre o utilizador.

> **Before we start...**
>
> **How should I refer to you?**

Opções:

* **Guy**
* **Girl**
* **Something else**
* **I don't want to say**

A escolha não deve ser obrigatória.

O utilizador pode continuar sem responder.

A IA deve respeitar a resposta escolhida.

A opção **Something else** pode abrir um campo opcional para o utilizador escrever como prefere ser tratado.

A opção **I don't want to say** não deve criar qualquer problema no funcionamento da IA.

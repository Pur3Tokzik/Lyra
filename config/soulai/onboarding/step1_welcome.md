# SoulAI 0.0.1 — ONBOARDING

## 2. Início

Ao abrir a SoulAI pela primeira vez, o utilizador vê uma apresentação simples.

A interface deve possuir uma animação suave.

A SoulAI apresenta o projeto.

> **Welcome to SoulAI.**

Depois:

> **SoulAI is the system.**
>
> **The AI you create here will be yours.**

A SoulAI explica brevemente que cada instalação começa de novo.

> **Every AI starts from zero.**

O utilizador deve carregar num botão para continuar.

### Botão

> **Begin**

Não existe botão para ignorar completamente o onboarding.
